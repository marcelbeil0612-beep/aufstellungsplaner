Häufige Fragen

Muss ich einen Account erstellen?

Nein. FormaXI läuft komplett lokal in deinem Browser. Kein Account, kein Passwort, keine E-Mail-Adresse nötig.

Wo werden meine Daten gespeichert?

Ausschließlich auf deinem Gerät, im lokalen Browserspeicher. Keine Daten werden an Server übertragen oder in einer Cloud gespeichert.

Funktioniert FormaXI auch ohne Internet?

Ja. Nach dem ersten Laden läuft die App komplett offline. Du kannst sie auch als PWA installieren – dann verhält sie sich wie eine native App.

Für welche Geräte ist FormaXI geeignet?

Für alle modernen Smartphones, Tablets und Computer – Android, iOS, Windows, macOS. Alles was einen Browser hat, läuft FormaXI.

Was ist das Systembuch?

81 taktische Duelle System gegen System in vier Spielphasen (Aufbau, Ballbesitz, Umschalten, Pressing). Für jeden, der tiefer in die Taktik einsteigen möchte – kostenlos gibt's 3 Duelle, Pro schaltet alle 81 frei.

Kann ich meine Lizenz auf mehreren Geräten nutzen?

Ja. Beim Kauf wird Pro auf deinem Gerät freigeschaltet. In der App findest du deinen persönlichen Lizenzschlüssel (oben rechts unter „Pro · Lizenz") — den fügst du auf weiteren Geräten unter „Schon gekauft? Lizenzschlüssel einlösen" ein, dann ist Pro auch dort aktiv.
